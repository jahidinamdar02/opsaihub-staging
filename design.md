# OpsAIHub Design System

Locked design system for Tim Hortons India OpsAIHub platform.

## Brand Colors (Locked)

- **Primary Red:** #C8102E (Tim Hortons Red)
- **Dark Red:** #9B0D22
- **White:** #FFFFFF
- **Dark:** #1A1A1A

## Neutral Palette

- **Surface:** #FAFAFA
- **Card:** #FFFFFF
- **Border:** #E8E8ED
- **Divider:** #F2F2F7

## Text Colors

- **Primary:** #1D1D1F
- **Secondary:** #6E6E73
- **Tertiary:** #8E8E93

## Status Colors

- **Success:** #34C759
- **Warning:** #FF9500
- **Critical:** #FF3B30

## Tints

- **Red tint:** rgba(200,16,46,0.08)
- **Green tint:** rgba(52,199,89,0.10)
- **Amber tint:** rgba(255,149,0,0.10)

## Typography

- **Display font:** Geist (600-700 weight)
- **Body font:** Geist (400-500 weight)
- **Scale:** Major third (1.25 ratio)

## Spacing Scale

- **xs:** 4px
- **sm:** 8px
- **md:** 16px
- **lg:** 24px
- **xl:** 32px
- **2xl:** 48px
- **3xl:** 64px

## Layout

- **Max width:** 1200px
- **Border radius:** 12px
- **Nav height:** 64px

## Shadows

- **Small:** 0 1px 3px rgba(0,0,0,0.04)
- **Medium:** 0 4px 12px rgba(0,0,0,0.06)
- **Large:** 0 8px 24px rgba(0,0,0,0.08)

## Design Principles

1. **Laptop-first:** Optimized for area managers on laptops
2. **Luxury feel:** Apple Store aesthetic, clean and minimal
3. **Brand consistency:** Tim Hortons colors are locked
4. **Accessibility:** WCAG 2.1 AA compliant
5. **Performance:** No heavy libraries, pure CSS/JS

## Macrostructure

- **Primary:** Bento Grid (dashboard sections)
- **Nav:** N1b three-section
- **Footer:** Ft2 inline rule single line

## Genre

- **Modern-minimal:** Clean, polished, enterprise feel
